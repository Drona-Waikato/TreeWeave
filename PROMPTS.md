## 1. Create a project management software with a visual interface, that runs on a local web server. 

Should show a compact hierarchical view, using lines, in a tree structure that shows a person’s total time commitment.

A line at the top level is composed of several fine lines. Each fine line from a separate subtree.

The thickness of a line shows how many separate projects exist in that subtree

When you click on the line a subtree view shows all the projects as connected bubbles to the tree.

Then you click on the project, which shows up as a pane.

In the pane, you can click and add a post-it note.
	In the post it note you can choose colour
	You can add a date, as the date approaches it becomes urgent. 
		Default urgency is 1 day, you can change the urgency notification
	

At the bottom of the pane are three buckets, To-Do, Doing, Done. Each post-it note has a connector bubble at the bottom, you a connect a note to a list. 

If you connect a note to the done list, it is minimised into just a very thin line and stacked over the last done post-it.
